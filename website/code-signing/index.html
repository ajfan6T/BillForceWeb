Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

BILLFORCE has applied to the SignPath Foundation for free code signing. Until the application is approved, the installer is not signed, and Windows may show “Windows protected your PC” the first time it runs.

What is signed

  • The Windows installer Billforce-Setup.exe and the program files it installs (BILLFORCE.exe and its uninstaller).
  • Only files built from the public source code at github.com/ajfan6T/BillForceWeb, by the project's GitHub Actions build (.github/workflows/desktop.yml) from the main branch. Nothing built on a personal computer is signed.
  • The certificate is used for BILLFORCE only, never for other software. Third-party open source components are included as they are published by their authors; BILLFORCE does not sign them on their behalf.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. See the full privacy policy for what it connects to when you ask it to (for example Supabase Cloud Sync or sending a bill on WhatsApp).

Checking the signature

Once releases are signed: right-click Billforce-Setup.exe, choose Properties, then the Digital Signatures tab. The signer is SignPath Foundation. If a file claiming to be BILLFORCE is not signed this way, do not run it.

Reporting a problem

If you think a BILLFORCE file was signed by mistake, or the certificate is being misused, open an issue at github.com/ajfan6T/BillForceWeb/issues.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

BILLFORCE has no accounts with us, no advertising, no analytics, no crash reports and no automatic update checks. The BILLFORCE project never receives your business data.

Where your data is kept

  • Windows app: on your computer, in %APPDATA%\BILLFORCE\data. Backups go to Documents\BILLFORCE Backups or the folder you choose.
  • Server edition: on the server where it is installed, which is run by you or the business that set it up.
  • Browser edition: in that browser on that computer.

When BILLFORCE connects to something, and only because you asked

  • Supabase Cloud Sync (off unless you turn it on in Settings): copies your business data to the Supabase project you set up with your own Supabase account. That copy is covered by Supabase's privacy policy.
  • Sending a bill on WhatsApp: when you click “Save & WhatsApp” or “WhatsApp”, BILLFORCE opens a wa.me link in your browser with the customer's number and a short message about the bill, and copies a picture of the bill for you to paste. What you send is covered by WhatsApp's privacy policy.
  • Links to this website or the download page open in your browser when you click them.
  • Printing goes to the printer you choose.
  • Backups are saved where you choose: a folder, a pen drive, or a cloud drive folder (OneDrive, Google Drive) that you set up yourself.

This website

This website is hosted on GitHub Pages; see the GitHub privacy statement. It sets no cookies and has no analytics. The home page asks GitHub for the latest version number and download size to show them. Downloads come from the project's GitHub Releases page.
